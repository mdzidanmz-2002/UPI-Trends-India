# UPI Trends in India

**End-to-end data analytics project** exploring the growth and evolution of India's Unified Payments Interface (UPI) from April 2016 to October 2026.

**Author:** Md Zidan

## Project Overview

This project analyses monthly UPI transaction statistics published by the National Payments Corporation of India (NPCI). It examines transaction volume, transaction value, average transaction value, and the growth in participating banks.

The project uses Microsoft Excel, MySQL, and Power BI to demonstrate the complete data analytics workflow, from data preparation and analysis to interactive dashboard development.

## Project Objectives

- Analyse the long-term growth of UPI transactions in India.
- Track changes in transaction volume and transaction value.
- Examine the expansion of banks participating in UPI.
- Calculate and analyse average transaction value.
- Identify yearly trends, growth patterns, and key insights.
- Present findings through an interactive Power BI dashboard.

## Tools and Technologies

- **Microsoft Excel:** Data cleaning, preparation, calculations, and PivotTable analysis.
- **MySQL:** Data validation, SQL queries, aggregations, and trend analysis.
- **Power BI:** Interactive dashboard and data visualisation.

## Key Findings

- UPI transaction activity expanded substantially over the study period.
- Participating banks increased significantly, reflecting the expansion of the UPI ecosystem.
- Transaction volume and transaction value continued to grow, although annual growth rates varied.
- Average transaction value showed a declining trend in recent years compared with its earlier levels.
- Monthly and yearly analysis revealed changes in transaction patterns over time.

## Data Source

**National Payments Corporation of India (NPCI)**

[UPI Product Statistics](https://www.npci.org.in/product/upi/product-statistics)

**Data Period:** April 2016 – October 2026

## Methodology and Data Notes

- Monthly UPI statistics were collected from NPCI.
- Data was cleaned and prepared using Microsoft Excel.
- SQL was used for data validation, aggregation, and trend analysis.
- Power BI was used to develop the final interactive dashboard.
- 2016 and 2026 represent partial calendar years.
- NPCI changed its reporting methodology in August 2018. This should be considered when comparing figures across the full study period.

## Conclusion

This project demonstrates how public UPI statistics can be transformed into meaningful insights using Excel, MySQL, and Power BI. It provides an overview of the expansion of digital payments in India and highlights important changes in transaction activity over time.
